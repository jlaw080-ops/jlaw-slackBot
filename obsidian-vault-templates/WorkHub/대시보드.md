# 📋 WorkHub 대시보드

> Dataview 플러그인이 필요합니다 (설정 → 커뮤니티 플러그인 → Dataview).

## ⚠️ 마감 지남
```dataview
TABLE WITHOUT ID file.link AS 할일, due AS 마감, priority AS 우선순위, notion_status AS Notion
FROM "WorkHub/Tasks"
WHERE due AND date(due) < date(today) AND status != "완료"
SORT due ASC
```

## 🎯 이번 주
```dataview
TABLE WITHOUT ID file.link AS 할일, due AS 마감, status AS 상태, priority AS 우선순위
FROM "WorkHub/Tasks"
WHERE due AND date(due) >= date(today) AND date(due) <= date(today) + dur(7 days)
SORT due ASC
```

## 🔄 진행 중
```dataview
LIST
FROM "WorkHub/Tasks"
WHERE status = "진행중"
```

## 🎫 Notion 티켓 연결됨
```dataview
TABLE WITHOUT ID file.link AS 할일, notion_status AS "Notion 상태", notion_ticket AS 링크
FROM "WorkHub/Tasks"
WHERE notion_ticket
```

## ▫️ 나머지 할일
```dataview
TABLE WITHOUT ID file.link AS 할일, priority AS 우선순위, tags AS 태그, source AS 출처
FROM "WorkHub/Tasks"
WHERE status != "진행중" AND (!due OR date(due) > date(today) + dur(7 days))
SORT priority ASC
```

## 📓 최근 작업일지
```dataview
LIST
FROM "WorkHub/Worklog"
SORT file.name DESC
LIMIT 7
```
