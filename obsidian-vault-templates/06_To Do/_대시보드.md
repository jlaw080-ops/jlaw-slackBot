# 📋 할일 대시보드

> Dataview 플러그인이 필요합니다. 이 파일은 `_`로 시작해 봇이 할일로 읽지 않습니다.

## ⚠️ 마감 지남
```dataview
TABLE WITHOUT ID file.link AS 할일, due AS 마감, priority AS 우선순위, project AS 프로젝트, notion-status AS Notion
FROM "06_To Do"
WHERE due AND date(due) < date(today) AND status != "done"
SORT due ASC
```

## 🎯 이번 주 마감
```dataview
TABLE WITHOUT ID file.link AS 할일, due AS 마감, status AS 상태, priority AS 우선순위
FROM "06_To Do"
WHERE due AND date(due) >= date(today) AND date(due) <= date(today) + dur(7 days) AND status != "done"
SORT due ASC
```

## 🔄 진행 중 / 검토 중
```dataview
LIST
FROM "06_To Do"
WHERE status = "in-progress" OR status = "review"
```

## 🎫 Notion 티켓
```dataview
TABLE WITHOUT ID file.link AS 할일, notion AS 구분, notion-status AS "Notion 상태", notion-url AS 링크
FROM "06_To Do"
WHERE notion AND status != "done"
SORT notion ASC
```

## ▫️ 예정 (planned)
```dataview
TABLE WITHOUT ID file.link AS 할일, project AS 프로젝트, priority AS 우선순위, created AS 생성
FROM "06_To Do"
WHERE status = "planned" AND (!due OR date(due) > date(today) + dur(7 days))
SORT priority ASC, created DESC
```

## ✅ 이번 달 완료
```dataview
LIST completed
FROM "06_To Do"
WHERE status = "done" AND completed AND dateformat(date(completed), "yyyy-MM") = dateformat(date(today), "yyyy-MM")
SORT completed DESC
```
